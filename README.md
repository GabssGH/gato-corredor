## 📌 Sobre o projeto

O Gato Corredor é um projeto desenvolvido com o objetivo de criar uma experiência simples, leve e divertida diretamente no navegador.

Além do entretenimento, o projeto também representa a aplicação prática de conceitos importantes do desenvolvimento web, como manipulação do DOM, lógica de programação, estilização e interatividade.

---

## ✨ Funcionalidades

- Interface intuitiva.
- Jogabilidade simples e acessível.
- Execução diretamente no navegador.
- Design leve e responsivo.
- Código desenvolvido do zero.

---

## 🛠️ Tecnologias utilizadas

- **HTML5** semântico
- **CSS3** (variáveis customizadas, grid, animações)
- **JavaScript** puro (sem frameworks), para a troca de abas e as animações de revelação
